# Security

## Reporting a problem

Report security problems privately through GitHub. Open the repository's
**Security** tab and choose **Report a vulnerability**. Please do not open a
public issue or pull request for them.

A useful report says which part is affected (toolkit, cloud scan, delivery API,
browser board, phone shortcut or device firmware), how to reproduce the problem
with invented data, and what an attacker could reach.

## Never share real school data

Issues, pull requests and their logs are public. Use invented children (Alfa and
Beta), an example school host and `example.*` addresses. Do not paste school
logins, session cookies, device tokens, gateway hostnames, scan output, messages
or screenshots of a real board. If a report only makes sense with real data, say
so in the private report and a private way to share it can be agreed.

## Supported versions

Only the latest `main` is maintained. There are no older releases that receive
fixes.
